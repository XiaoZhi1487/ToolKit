## 💡 这是什么？

**千工 · 工具箱** 是一站式的在线实用工具集合，把日常开发、办公、学习中最常用的小工具汇聚到一起，共 **140+ 款工具**，覆盖 **9 大分类**：

| 分类 | 代表工具 |
|------|---------|
| 🛠️ 开发者 | JSON 格式化、正则测试、SQL 格式化、JWT 解码、Gitignore 生成 |
| ✍️ 文本 | 文本分析、加密、去重、排序、Markdown 预览 |
| 🛡️ 安全 | 密码生成、哈希、文本加密、身份证校验、子网计算 |
| 🎨 设计 | 配色方案、渐变生成、字体搭配、设计令牌 |
| 🎬 媒体 | 图片压缩、裁剪、滤镜、二维码生成 |
| 🔄 转换 | 单位换算、进制转换、CSV/JSON/XML/YAML 互转 |
| ⏱️ 生产力 | 番茄钟、待办清单、倒计时、世界时钟、快捷回复 |
| 🤖 AI 工具 | 提示词优化、Token 计算、聊天记录切分 |
| 🧰 工具 | 备忘录、文件哈希、系统信息检测、截图标注 |

## ✨ 亮点

- **纯原生 · 离线可用** — 全部基于原生 JavaScript 实现，无任何依赖，关网也能用
- **中英双语** — 一键切换中英文界面，全球用户无压力
- **拼音搜索** — 中文输入太慢？直接输拼音首字母（如 `mm` 搜"密码"）秒匹配
- **深色/浅色主题** — 护眼暗色模式，熬夜写代码也不刺眼
- **最近使用** — 常用工具一键直达，面板可自由拖拽，刷新后自动恢复
- **响应式设计** — 手机、平板、电脑完美适配，随时随地开箱即用
- **隐私安全** — 所有数据本地处理，绝不经过任何服务器

**QianGong ToolKit** is an all-in-one collection of online utility tools that brings together the most useful little tools for daily development, office work, and study — **140+ tools** across **9 categories**:

| Category | Featured Tools |
|----------|---------------|
| 🛠️ Developer | JSON Formatter, Regex Tester, SQL Formatter, JWT Decoder, Gitignore Generator |
| ✍️ Text | Text Analyzer, Encryption, Deduplication, Sorting, Markdown Preview |
| 🛡️ Security | Password Generator, Hashing, Text Encryption, ID Card Validation, Subnet Calculator |
| 🎨 Design | Color Schemes, Gradient Generator, Font Pairing, Design Tokens |
| 🎬 Media | Image Compression, Cropping, Filters, QR Code Generator |

| 🤖 AI Tools | Prompt Optimizer, Token Calculator, Chat Log Splitter |
| 🧰 Utilities | Note Pad, File Hash, System Info Detection, Screenshot Annotation |

## ✨ Highlights

- **Pure Vanilla · Offline-Ready** — Built entirely with native JavaScript, zero dependencies, works even without internet
- **Bilingual** — One-click switch between Chinese and English
- **Pinyin Search** — Typing Chinese too slow? Just type pinyin initials (e.g. `mm` for "密码") for instant matches
- **Dark / Light Themes** — Eye-friendly dark mode for late-night coding sessions
- **Recent Tools** — One-click access to frequently used tools, draggable panel that restores on refresh
- **Responsive Design** — Perfectly adapted for mobile, tablet, and desktop
- **Privacy First** — All data is processed locally, never leaves your device
